# سامانه سلامت زنجیره اروند

سامانه هوشمند پایش سلامت سلول‌های الکترولیز، پیش‌بینی فولینگ راکتورهای PVC و بهینه‌سازی انرژی.

## قابلیت‌ها

- پیش‌بینی زوال غشا
- پیش‌بینی فولینگ اتوکلاو
- پیش‌بینی کیفیت محصول
- بهینه‌سازی برنامه تولید
- داشبورد و هشدار

## ساختار پروژه

services/ : سرویس‌ها
shared/ : بخش مشترک
docs/ : مستندات
tests/ : تست‌ها

## نحوه اجرا

pip install -r requirements.txt
uvicorn main:app --reload
